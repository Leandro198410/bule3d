# Bule 3d

Landing page for **Bule 3d** — fabricação e venda de peças impressas em 3D no Brasil.

Static single-page site (`index.html` only, no external dependencies).

## Contact

**loja.bule3d@gmail.com**

## GitHub Pages

1. Repo **Settings → Pages**
2. **Source:** Deploy from a branch
3. **Branch:** `main` / folder: `/ (root)`
4. Save and wait 1–2 minutes

Site URL (typical):

`https://leandro198410.github.io/bule3d/`

(Username path follows the GitHub account; if your login casing differs, use the exact URL shown under Pages after deploy.)
